# 🩺 Doctor's Visit Form

A simple and beginner-friendly HTML project that collects patient information before a doctor's appointment. This project demonstrates the use of various HTML form elements and input types.

## 📋 Features

- Patient name input
- Age input
- Gender selection (Radio Buttons)
- Visit type selection (Checkboxes)
  - First Visit
  - Follow-up
  - Check-up
- Email input
- Phone number input
- Symptoms text area
- Appointment date selection
- Appointment time selection
- Reason for visit text area
- Submit button

## 🛠️ Technologies Used

- HTML5

## 🚀 How to Run

1. Download or clone this repository.
2. Open `index.html` in any web browser.
3. Fill out the form.
4. Click **Submit**.
